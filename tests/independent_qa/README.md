# Wave 2 independent QA (W19)

This held-out manifest is separate from the existing CLI corpus and W18's authoring. It was generated from small closed-form mathematical families, with no fitted or captured solver answers. Baseline: `41d78278c50ca9f42c6050592613473bee1cfb6c`. Exact CLI invocations already in the baseline corpus were excluded. The manifest uses fixed enumerations (no random seed or sampling). It is a regression sample, not a coverage estimate.

Run `cargo test -p mathematishia-cli --test wave2_independent_cli -- --nocapture` and `cargo test -p mathematishia-kernel --test wave2_independent_certificates`. The CLI runs each invocation twice and checks exact semantic lines, full selected root/interval/condition lists, typed refusals and outcome status. It reports mismatches separately. Expected refusals are not solves; a partial root example is not completeness. No teaching-step verification is claimed by the CLI: final certificates and partial root examples are counted separately from checked steps. Kernel tests independently compare coefficients, root sets and signed branches; mutations challenge source binding, missing/extra roots, missing partition cells, incorrect signs and altered periodic angle evidence. No general period-family or general piecewise API exists in this baseline, so those mutation checks are gated on integration.

No time thresholds are asserted: process startup and CI scheduling vary across platforms. Exact polynomial degree and trig scalar-bit boundaries are tested. No production modules or shared interfaces are changed. Reclassify legacy refusals/partials only when new adapters and independent checks are integrated by the coordinator.
